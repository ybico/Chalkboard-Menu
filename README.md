# Chalkboard Menu

A chalkboard on an easel displaying a real-time food menu of a supposedly new opened restaurant—a setup suitable for small or medium-sized establishments but scalable to the needs of a large restaurant.
The administrator has access to a section for managing (creating, reading, updating, and deleting) users and menu items. Non-administrative users are limited to managing food menu items only.
This application leverages the power of Meteor and React to provide real-time data updates; it is also highly customizable—allowing for adjustments to styles, colors, content, and more—to suit various types of businesses.
